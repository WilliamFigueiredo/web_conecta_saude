# Conecta Saúde BR

Projeto final do curso de desenvolvimento web (TripleTen). Portal fictício de saúde inspirado nos serviços digitais do SUS, com login, prontuário eletrônico, nutrição, exercícios e um assistente virtual.

Deploy: https://web-conecta-saude-black.vercel.app/

## Tecnologias usadas

- React
- Vite
- React Router
- CSS puro (BEM)
- API pública RandomUser.me (dados de profissionais)

## Sobre o projeto

Essa entrega é só o front-end. O login/cadastro estão funcionando de forma simulada (sem back-end de verdade ainda), só pra demonstrar a interface e o fluxo.

O back-end (Node/Express + MongoDB, com autenticação JWT) já está em desenvolvimento na branch `develop-backend` e será integrado numa próxima etapa.
